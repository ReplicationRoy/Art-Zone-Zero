# VOID FRAME — ZZZ Fan Art Gallery

Unofficial static fan-art gallery for Zenless Zone Zero.

## Current status

The site source is being prepared in this private repository. **GitHub Pages is intentionally not enabled yet.**

## Before publishing

1. Replace the gallery placeholders with actual artwork.
2. Review character categories, titles, site name, and legal/fan-project notice.
3. Confirm mobile and desktop layouts.
4. Only after final approval, configure GitHub Pages and make the intended public-facing settings.

## Artwork structure

When artwork is ready, add image assets to an `assets/` directory and replace each `.art-placeholder` block in `index.html` with an image element such as:

```html
<img class="gallery-image" src="assets/ellen-01.jpg" alt="Ellen Joe fan art">
```

Only upload images you have the right to publish.
